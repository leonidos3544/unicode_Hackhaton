# Афиша культуры Башкортостана

Поиск культурных мероприятий на сайте и в Telegram. Пользователь выбирает фильтры или пишет обычным сообщением: «Спектакли в Стерлитамаке», «15 ноября вечером», «С ребёнком 12 лет», «До 700 рублей на человека».

В проекте есть каталог, ИИ-помощник, подписки, уведомления, административная панель, импорт мероприятий, сбор открытых афиш и планировщик дня. Сайт и бот используют общую базу данных.

**Организаторам:** начните с запуска ниже. Ключи ИИ и Telegram для проверки каталога и админки не нужны. [Сценарий демонстрации на 5 минут](docs/DEMO_5_MIN.md) · [Короткая шпаргалка](docs/DEMO_CHEATSHEET.md).

## Быстрый запуск

Нужен работающий **Docker Desktop с Linux-контейнерами** или Docker Engine с Docker Compose. Отдельно устанавливать Python, Node.js и PostgreSQL не требуется. При первом запуске нужен интернет для загрузки Docker-образов и зависимостей.

### Windows

Откройте PowerShell:

```powershell
git clone https://github.com/leonidos3544/unicode_Hackhaton.git
cd unicode_Hackhaton
.\start.cmd
```

Можно также скачать ZIP репозитория, распаковать его и запустить `start.cmd` из папки проекта.

### Linux и macOS

```bash
git clone https://github.com/leonidos3544/unicode_Hackhaton.git
cd unicode_Hackhaton
sh start.sh
```

Первый запуск занимает несколько минут. Скрипт сам:

1. Собирает приложение и создаёт `.env` со случайными локальными паролем базы и ключом администратора.
2. Запускает PostgreSQL, применяет миграции, поднимает API и сайт.
3. Загружает сохранённый набор реальных мероприятий, если каталог пуст.
4. Запускает сбор свежих афиш, обработку уведомлений и Telegram-бота при наличии его токена.

Существующий `.env` и заполненная база сохраняются. Повторный запуск не создаёт копии начальных мероприятий.

### Что открыть

| Что проверить | Адрес |
|---|---|
| Каталог и фильтры | http://localhost:8081/ |
| Диалог с помощником | http://localhost:8081/chat |
| Подписки и уведомления | http://localhost:8081/personal |
| Админка | http://localhost:8081/admin |
| Планировщик дня | http://localhost:8081/planner |
| Встраиваемая афиша | http://localhost:8081/widget |
| Документация API | http://localhost:8000/docs |
| Проверка готовности | http://localhost:8081/health/ready |

Для входа в админку откройте **локальный файл `.env`**, скопируйте значение после `ADMIN_API_TOKEN=` и вставьте его в поле «Ключ доступа». Логин и пароль пользователя не нужны. Не публикуйте этот файл.

Адреса относятся к стандартным портам. Если вы поменяли `WEB_PORT` или `API_PORT` в `.env`, используйте свои значения. `localhost` доступен на компьютере, где запущен проект; это не опубликованный сайт.

## Как проверить решение за несколько минут

1. В каталоге выберите Стерлитамак и категорию «Театр». Откройте карточку и её первоисточник.
2. В админке посмотрите «Карточки», «Импорты», «Сборы» и «Модерация».
3. Если подключён ИИ, откройте чат и последовательно уточняйте город, дату, возраст и бюджет. Enter отправляет запрос, Shift+Enter переносит строку.
4. В планировщике задайте день, бюджет и состав группы. При недостатке подтверждённых данных сервис объяснит причину отсутствия плана.

Начальный набор — сохранённая реальная афиша ноября 2026 года, со ссылками и датой сбора. Это ограниченный охват двух городов, а не полная афиша республики. Прошедшие сеансы не показываются в обычном поиске; при проверке после окончания дат снимка дождитесь свежего сбора или добавьте актуальное мероприятие через админку.

## Как добавляются мероприятия

Есть три способа. Все они используют общий каталог и проверки данных.

### 1. Автоматически с открытых сайтов

Процесс `sources` читает официальные афиши Башкирской филармонии, Стерлитамакского театрально-концертного объединения и Русского драмтеатра в Уфе. Он запускается вместе с проектом и повторяет сбор каждые шесть часов.

Сборщик извлекает сеансы, проверяет площадку и адрес, сохраняет исходные страницы, ссылки и время проверки. Подтверждённые сведения могут публиковаться автоматически. Противоречия отправляются в раздел **«Модерация»**. Если сайт недоступен, приложение не подставляет выдуманные данные.

Для ручного обновления прямо сейчас:

```bash
docker compose exec sources uv run --no-sync python -m app.cli.collect_sources --publish-verified
```

Источники настроены в `config/sources.json`. Подключение сайта с другой разметкой может потребовать нового парсера.

### 2. Вручную через админку

1. Откройте `/admin` и войдите ключом из `.env`.
2. На вкладке **«Карточки»** нажмите **«Создать карточку»**.
3. Заполните название, категорию, дату со временем, город, площадку, адрес и ссылку на источник. Остальные сведения указывайте по известным данным.
4. Сохраните карточку. Она появится как черновик и пока не будет видна пользователям.
5. Проверьте сведения. В действиях выберите **«Опубликовать»**, укажите причину и нажмите **«Применить»**.

Действие «Отменить» убирает сеанс из подборок. Его постоянная карточка сохраняется с отметкой об отмене. История изменений доступна в разделе «Аудит».

### 3. Загрузить CSV или JSON

1. В админке откройте **«Импорты»**.
2. Укажите стабильное название источника и загрузите файл.
3. Посмотрите отчёт: какие строки добавлены, обновлены, отклонены или отправлены на модерацию.
4. Проверьте и отдельно опубликуйте созданные черновики.

Шаблон CSV: [data/import-template.csv](data/import-template.csv). Примеры формата JSON с реальными событиями: [data/open/sgtko.json](data/open/sgtko.json). Правила полей и публикации: [добавление мероприятий](docs/ADDING_EVENTS.md).

`external_id` должен оставаться одинаковым для одного сеанса при повторных загрузках. Повтор той же записи не создаёт новый сеанс; изменения и противоречия проходят проверку. Неизвестная цена остаётся неизвестной и не означает бесплатный вход.

## Подключение ИИ и Telegram

Без ключа модели чат использует обычный поиск и явно показывает этот режим. Для настоящего ИИ заполните в `.env` `LLM_API_URL`, `LLM_MODEL`, `LLM_API_KEY` и тарифы. Настройки Cloud.ru и лимитов: [docs/CLOUD_RU.md](docs/CLOUD_RU.md).

Для своего Telegram-бота задайте `TELEGRAM_BOT_TOKEN` и `TELEGRAM_BOT_USERNAME`. Один токен должен обслуживать один запущенный polling-процесс. Команды и проверки: [docs/TELEGRAM_AI.md](docs/TELEGRAM_AI.md).

После изменения `.env`:

```bash
docker compose up -d api bot
```

В боте отправьте `/chat`, затем обычный запрос. Подписка создаётся после подтверждения кнопкой. Командный поиск доступен через `/search`. Ключи команды не включены в репозиторий: организаторы используют свои ключи либо проверяют режим без ИИ и бота.

## Остановка и повторный запуск

Windows:

```powershell
.\start.cmd stop
.\start.cmd
```

Linux/macOS:

```bash
sh start.sh stop
sh start.sh
```

Остановка сохраняет данные PostgreSQL в Docker-томе. Не используйте `docker compose down -v`, если хотите сохранить каталог, историю и подписки.

## Если не запускается

| Что произошло | Что сделать |
|---|---|
| Docker не найден или выключен | Установить и открыть Docker Desktop; дождаться готовности, повторить запуск |
| Занят порт | В `.env` изменить `WEB_PORT`, `API_PORT` или `POSTGRES_PORT`. Для сайта также обновить `PUBLIC_BASE_URL`; для локального Python — порт в `DATABASE_URL` |
| Карточек нет | Проверить будущие даты, убрать строгие фильтры. Посмотреть «Сборы» в админке; добавить актуальную карточку вручную |
| ИИ не отвечает | Проверить настройки и тариф; обычный поиск остаётся доступен |
| Не работает Telegram | Проверить токен и отсутствие второго процесса с тем же токеном; смотреть `docker compose logs --tail 30 bot` |
| API не прошёл проверку готовности | Посмотреть `docker compose logs --tail 50 api migrate postgres`; проверить совпадение пароля с существующим томом PostgreSQL |

Изменение `POSTGRES_PASSWORD` после первого запуска не меняет пароль уже созданной базы. Сохраните прежнее значение либо меняйте пароль базы отдельной административной процедурой.

## Проверки и устройство проекта

Для разработки нужны Python 3.12, uv и Node.js 24. Для обычного запуска они не требуются.

```powershell
uv sync --locked
.\scripts\test.ps1
.\scripts\browser-test.ps1
```

Тесты используют отдельную базу `bashculture_test`. Приложение хранит основной каталог в `bashculture`.

```bash
cd frontend
npm ci
npm test
npm run build
```

Backend: Python, FastAPI, SQLAlchemy, Alembic, PostgreSQL. Frontend: React и TypeScript. Telegram подключён через HTTP API. Задания, подписки и история сохраняются в PostgreSQL; Redis не используется.

```text
Открытые афиши → сбор и проверка → каталог PostgreSQL
                                      ↑
Сайт / Telegram → общий сервер → ИИ и инструменты поиска
                                      ↓
                   карточки, подписки, уведомления, план дня
```

Результаты проверки и ограничения: [docs/VALIDATION.md](docs/VALIDATION.md). Планировщик требует известных цен, времени окончания и проверяемых перемещений; его учебный режим с явно помеченными допущениями не равен подтверждённому маршруту. Публичный VPS пока не развёрнут; подготовка размещения — [docs/HOSTING.md](docs/HOSTING.md).
