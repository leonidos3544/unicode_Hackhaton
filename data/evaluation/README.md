# Каталог для воспроизводимой оценки

`catalog.json` — один сохранённый снимок публичной выдачи из 82 карточек, использованный при оценке 14 ноября 2026 года с фиксированным временем `2026-11-14T12:00:00+00:00`.

Он нужен только для восстановления отдельной базы `bashculture_agent_eval` скриптом `scripts/agent-eval.ps1`. При обычном запуске приложение использует `data/open/` и свежий сбор источников. Снимок оценки не является новой проверкой актуальности афиши и не содержит ключей, личной истории или подписок.
