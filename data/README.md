# Данные афиши

`open/` содержит сохранённые реальные афиши и сведения о площадках. Начальный каталог загружается из этих файлов только в пустую базу. Фоновый сборщик обновляет данные с официальных сайтов.

`import-template.csv` — заголовок CSV для загрузки своей афиши; `event.schema.json` описывает поля. Реальный пример JSON — `open/sgtko.json`.

В файлах время передаётся с часовым поясом, цены — в рублях. Неизвестные цена, возраст и окончание остаются пустыми. Для стабильного обновления сохраняйте `external_id` и название источника.

`evaluation/` — отдельный публичный снимок для воспроизводимой оценки на фиксированном времени. Он не используется как актуальный каталог при обычном запуске.

Порядок добавления, публикации и модерации: [ADDING_EVENTS.md](../docs/ADDING_EVENTS.md). Искусственные записи из тестов загружаются только в тестовую базу и не входят в каталог сервиса.
